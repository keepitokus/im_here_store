# Редактор книги

- Найди нужный SKU в `src/lib/catalog.ts` и подсказки в `src/lib/editor-copy.ts`. Для тематических правок сравни выбранное издание с соседним. Пример в пустом поле должен оставаться визуальной подсказкой и отсутствовать в сохранённом черновике и у получателя.
- Проследи сценарий по нужному входу. Серверный редактор начинается в `src/app/create/[slug]/page.tsx` и `src/components/editor-wizard.tsx`. Для Pages экспорт подставляет `src/components/free-editor.tsx`, который работает с браузерным хранением. Для чтения смотри `src/components/book-reader.tsx` и `src/components/book-timeline.tsx`.
- Для изменений хронологии проверь добавление и перестановку событий, сохранение и повторное открытие, затем соответствие предпросмотру. Для изменений записи медиа проверь успешную запись и отказ в разрешении; отдельно отмечай, что было проверено на Safari iOS и Chrome Android.
- Выбери проверки по области правки. `tests/editor-copy.test.ts` и `tests/content-themes.test.ts` покрывают тематический контент. Для поведения в браузере сначала найди подходящий сценарий в `tests/*.spec.ts`. Используй синтетические воспоминания и медиа.
